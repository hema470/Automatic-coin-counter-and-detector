# Automatic Coin Counter and Detector

This project is an automatic coin counter and detector. It uses computer vision techniques to identify and count coins from images or video streams.

## Features
- Coin detection using OpenCV.
- Automatic counting and value estimation.
- Web-based frontend for easy interaction.

## Installation
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python run.py`

## Usage
- Upload an image of coins to the web interface.
- View the detected coins and the total count.
